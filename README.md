# BÀI 6: GIAO TIẾP HIỆU QUẢ KHI GẶP LỖI LẬP TRÌNH

## 1. Tin nhắn gửi giảng viên

Em chào thầy/cô ạ!

Em đang sử dụng Windows 11 và VS Code (PowerShell) để thực hành cài đặt Git. Khi nhập lệnh `git init`, em mong muốn khởi tạo Git thành công cho thư mục dự án nhưng Terminal lại báo lỗi `git: command not found`, khiến em không thể tiếp tục.

Em gửi kèm ảnh chụp màn hình có lệnh đã nhập và thông báo lỗi. Nhờ thầy/cô hướng dẫn em cách khắc phục ạ.

Em cảm ơn thầy/cô!

``` 
1. Context (Bối cảnh):

Hệ điều hành: Windows 11.

Công cụ: VS Code, PowerShell.

Công việc: Cài đặt và sử dụng Git để quản lý mã nguồn.

2. Expected (Mong muốn):
Sau khi nhập lệnh git init, Git sẽ được khởi tạo thành công trong thư mục dự án.

3. Actual (Thực tế):
Terminal hiển thị thông báo git: command not found, khiến em không thể thực hiện lệnh Git.

4. Log & Screenshot (Mã lỗi và ảnh chụp):

Mã lỗi: git: command not found.

Em gửi kèm ảnh chụp màn hình Terminal có hiển thị lệnh đã nhập và thông báo lỗi.
```


## 2. Hai mẹo chụp ảnh

***Mẹo 1: Chụp ảnh rõ nội dung lỗi***
- Sử dụng Windows + Shift + S để chụp màn hình.
- Chỉ chọn vùng Terminal có lệnh git init và thông báo lỗi.
- Đảm bảo chữ rõ nét, không bị che khuất.
  
***Mẹo 2: Bảo vệ thông tin cá nhân***
- Che hoặc cắt bỏ email, tên tài khoản, đường dẫn chứa thông tin cá nhân nếu không cần thiết.
- Không để lộ mật khẩu, Access Token, API Key hoặc thông tin đăng nhập trong ảnh.
